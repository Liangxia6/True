# 25 个目标产品自动化可行性核查

> 版本：v0.2
> 初次核查：2026-08-17
> 最近更新：2026-08-18
> 范围：仅记录 25 个具体目标产品的入口、目标模式、执行渠道、自动化状态、风险和下一步核验事项。

## 状态说明

| 状态 | 含义 |
|---|---|
| `AUTOMATION_VALIDATED_MVP` | 已用真实账号和真实任务验证输入、提交、等待与正文采集 |
| `WEB_CANDIDATE` | 有明确 Web 产品面，等待授权与影子运行 |
| `API_CONFIRMED` | 官方 API 已确认，应作为独立 Product Mode |
| `HYBRID_REQUIRED` | 仅测 Web 会漏掉主要桌面或跨组件能力 |
| `BUILD_THEN_RUN` | 企业构建平台；先冻结 Agent，再通过发布 Web/API 重复运行 |
| `MODE_UNVERIFIED` | 产品存在，但目标 AI 模式或功能尚未由官方资料和登录态确认 |
| `RESTRICTED_PENDING_AUTH` | 条款明确限制自动化，取得书面授权前不得正式自动运行 |
