# 豆包网页版自动化脚本使用说明

当前脚本完成最小闭环：打开豆包网页版、等待人工登录、创建新对话、选择“深入研究”、输入提示词、等待输出，并保存结果和证据。

## 安装

```bash
npm install
```

脚本默认调用本机 Google Chrome，不需要下载 Playwright 自带浏览器。首次运行会创建独立 Profile：`.trueeval/profiles/doubao`。

## 运行

```bash
npm run doubao -- --prompt "请调研并比较2026年主流Research Agent的能力与适用场景"
```

也可以从文件读取问题：

```bash
npm run doubao -- \
  --prompt-file ./question.txt \
  --task-id research-001 \
  --timeout-seconds 2700
```

第一次运行时：

1. 脚本打开独立 Chrome 窗口；
2. 如果显示未登录，请在该窗口手动登录豆包；
3. 脚本检测到登录完成后自动继续；
4. 不要同时用另一个 Chrome 进程打开同一个 `.trueeval/profiles/doubao`。

## 输出

每次运行创建独立目录：

```text
artifacts/doubao/<task-id>-<run-id>/
├── request.json
├── events.jsonl
├── result.json
├── response.visible.md
├── response.raw.html
├── citations.raw.json
├── page.visible.txt
└── *.png
```

`result.json` 是后续 BenchmarkAdapter 使用的统一结果。豆包网页未显示的数据保持 `null`，不会猜测模型版本、token 或费用。

只验证页面、登录态和“深入研究”模式而不发送提示词：

```bash
npm run doubao -- --prompt "不会被发送" --probe-only --allow-anonymous
```

## 常用参数

```bash
npm run doubao -- --help
```

- `--chat-mode`：不选择“深入研究”，只测试普通对话；
- `--probe-only`：只探测页面和模式切换，不发送提示词；
- `--allow-anonymous`：仅用于未登录页面探测；当前豆包可能在实际提交后终止匿名会话，正式任务应登录；
- `--keep-open`：运行后保留浏览器，便于排查；
- `--headless`：无头运行，仅适用于已经有有效登录态；
- `--login-timeout-seconds`：人工登录等待时间；
- `--timeout-seconds`：研究任务最长等待时间；
- `--profile-dir`：指定另一个独立账号环境。

## 安全边界

脚本不绕过验证码、设备验证、付费、限流和服务协议，不使用 stealth、代理轮换或豆包未公开内部接口。验证码或安全验证必须由真人完成。
